# Vantastic Transit website

Static site plus a small Cloudflare Worker for the three forms.
Vantastic Transit LLC, 117 S Washington St, Suite 106, Lake City, MN 55041. Phone (507) 272-4901.
Built 2026-10-24. Lead Landing is the ONLY CRM.

Pages: `/`, `/facilities/`, `/drive/`, `/thanks/` (noindex), `404.html`.
Pages are generated by `tools/build_site.py`; edit that script and re-run, or edit the HTML directly.

Form flow: `POST /api/request` (worker.js) with `kind` = ride | facility | driver -> matching Lead Landing form.
Form ids are empty until the LL sub-account exists: fill `LL_FORMS` in worker.js or set Worker variables
`LL_FORM_RIDE`, `LL_FORM_FACILITY`, `LL_FORM_DRIVER`. Until then the forms show "please call us".

Deploy: Cloudflare Workers + Static Assets, Worker name `vantastic` (wrangler.jsonc). Connect the repo in Cloudflare; push to `main` deploys.
Domain vantastictransit.net (Cloudflare). www redirects to the bare domain in worker.js.

## Before launch (owners confirm)
- Vans have ramp/lift and tie-downs; drivers have background studies; vans inspected and insured.
- Office hours M-F 8-5 (from state listing).
- No prices on the site until the rate card is approved. Medical Assistance is "call and ask" until DHS approves the new owners.
- Add real photos of the van and owners.
